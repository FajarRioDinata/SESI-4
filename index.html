🎭 Slide 2: Pengantar Polimorfisme

Arti: "Banyak bentuk" (poly = banyak, morph = bentuk). Objek dari subclass dapat diperlakukan sebagai objek superclass.
💡 Contoh: Kucing, Anjing, Burung adalah Hewan.

Runtime polymorphism di Dart melalui method overriding (compile-time overloading tidak didukung).

🔄 Slide 3: Polimorfisme dengan Inheritance

📌 Referensi tipe parent dapat menampung objek child.

class Bentuk {
  void gambar() => print('Menggambar bentuk');
}

class Lingkaran extends Bentuk {
  @override
  void gambar() => print('Menggambar lingkaran');
}

class Persegi extends Bentuk {
  @override
  void gambar() => print('Menggambar persegi');
}

void main() {
  Bentuk bentuk1 = Lingkaran(); // Polimorfisme
  Bentuk bentuk2 = Persegi();   // Polimorfisme
  bentuk1.gambar(); // Output: Menggambar lingkaran
  bentuk2.gambar(); // Output: Menggambar persegi
}

✅ Keuntungan Polimorfisme

1. Fleksibilitas: Kode bekerja dengan berbagai tipe
2. Extensibility: Mudah menambah tipe baru
3. Code Reusability: Method umum di superclass
4. Maintainability: Perubahan mudah dikelola

🔍 Slide 5: is dan as Operator

is : Mengecek tipe objek  |  as : Casting tipe objek

class Kendaraan {}
class Mobil extends Kendaraan {
  void klakson() => print('Tin!');
}

void main() {
  Kendaraan k = Mobil();

  if (k is Mobil) {          // Cek tipe
    (k as Mobil).klakson();  // Casting
  }
  
  // Safe casting dengan as? (Dart 2.15+)
  (k as? Mobil)?.klakson();
}

📦 Slide 8: Abstract Class

🔹 Tidak bisa diinstansiasi langsung.
🔹 Dapat memiliki method abstract (tanpa implementasi) dan concrete.

abstract class Kendaraan {
  String? merk;   // Field concrete
  void start();   // Method abstract
  void stop() {   // Method concrete
    print('Kendaraan berhenti');
  }
}

class Mobil extends Kendaraan {
  @override
  void start() {
    print('Mobil $merk menyala');
  }
}

🎵 Slide 9: Abstract Method

Method tanpa body, harus di-override di subclass.

abstract class AlatMusik {
  void mainkan();   // Abstract method
  void info() {     // Concrete method
    print('Ini adalah alat musik');
  }
}

class Gitar extends AlatMusik {
  @override
  void mainkan() {
    print('Jreng jreng...');
  }
}

🔌 Slide 10: Interface di Dart

Sejak Dart 3.0: interface class. Gunakan implements untuk mengimplementasi kontrak.

interface class Flyable {
  void terbang() => print('Terbang...');
}

class Bird implements Flyable {
  @override
  void terbang() => print('Burung terbang tinggi');
}

class Plane implements Flyable {
  @override
  void terbang() => print('Pesawat terbang cepat');
}

⚙️ Slide 12: Static Members dan Method

Static member adalah properti/method milik class itu sendiri, diakses via nama class. Berguna untuk utility class.

class MathUtils {
  static double pi = 3.14;
  static int add(int x, int y) {
    return x + y;
  }
}

void main() {
  print('Nilai pi : ${MathUtils.pi}');
  print('Result : ${MathUtils.add(10, 20)}');
}
💡 Catatan: Pada contoh asli slide terdapat typo Mathutils, pastikan menggunakan MathUtils (case-sensitive).

🚀 Challenge: Sistem MediaPlayer

Buat sistem dengan:
• Abstract class: MediaPlayer
• Interface: Playable, Pausable
• Class implementasi: AudioPlayer, VideoPlayer

abstract class MediaPlayer { void play(); }
interface class Playable { void play(); }
interface class Pausable { void pause(); }

class AudioPlayer implements MediaPlayer, Playable, Pausable {
  @override void play() => print('Audio diputar');
  @override void pause() => print('Audio dijeda');
}

class VideoPlayer implements MediaPlayer, Playable, Pausable {
  @override void play() => print('Video dimainkan');
  @override void pause() => print('Video pause');
}

void main() {
  List<MediaPlayer> daftar = [AudioPlayer(), VideoPlayer()];
  for (var player in daftar) {
    player.play();
    if (player is Pausable) (player as Pausable).pause();
  }
}

🧮 MathUtils (Static Methods – Latihan nomor 5)

import 'dart:math';

class MathUtils {
  static int factorial(int n) {
    if (n < 0) throw ArgumentError('Tidak untuk negatif');
    return n <= 1 ? 1 : n * factorial(n - 1);
  }
  
  static bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i <= sqrt(n); i++) if (n % i == 0) return false;
    return true;
  }
  
  static double roundToDecimals(double value, int decimals) {
    double mod = pow(10, decimals).toDouble();
    return (value * mod).round() / mod;
  }
  
  static int randomInt(int min, int max) => min + Random().nextInt(max - min + 1);
  static double randomDouble(double min, double max) => min + Random().nextDouble() * (max - min);
  
  static double mean(List<num> numbers) {
    if (numbers.isEmpty) return 0;
    return numbers.reduce((a,b) => a + b) / numbers.length;
  }
  
  static double median(List<num> numbers) {
    if (numbers.isEmpty) return 0;
    List<num> sorted = List.from(numbers)..sort();
    int mid = sorted.length ~/ 2;
    if (sorted.length.isEven) {
      return (sorted[mid - 1] + sorted[mid]) / 2;
    }
    return sorted[mid].toDouble();
  }
}

🎭 Polimorfisme: Banyak Bentuk

Arti: poly (banyak) + morph (bentuk). Objek dari subclass dapat diperlakukan sebagai objek superclass.

Runtime polymorphism di Dart melalui method overriding (compile-time overloading tidak didukung).

class Bentuk { void gambar() => print('Menggambar bentuk'); }
class Lingkaran extends Bentuk { @override void gambar() => print('Menggambar lingkaran'); }
class Persegi extends Bentuk { @override void gambar() => print('Menggambar persegi'); }

void main() {
  Bentuk bentuk1 = Lingkaran();  // Polimorfisme
  Bentuk bentuk2 = Persegi();
  bentuk1.gambar(); // Menggambar lingkaran
  bentuk2.gambar(); // Menggambar persegi
}

🐾 Praktik 1 – Polimorfisme dengan List

Buat list List<Hewan> berisi berbagai subclass (Kucing, Anjing, Burung). Panggil method bersuara() secara polimorfik.

abstract class Hewan { void bersuara(); }
class Kucing extends Hewan { @override void bersuara() => print('Meong'); }
class Anjing extends Hewan { @override void bersuara() => print('Guk guk'); }
class Burung extends Hewan { @override void bersuara() => print('Cuit cuit'); }

void main() {

}

🧩 Abstraksi: Menyembunyikan Detail Implementasi

Abstract class di Dart menggunakan keyword abstract. Bisa berisi method abstract (tanpa body) dan method konkrit.

abstract class AlatMusik {
  void mainkan(); // abstract method
  void info() { print('Ini adalah alat musik'); } // concrete
}

class Gitar extends AlatMusik {
  @override
  void mainkan() => print('Jreng jreng...');
}
🎯 Tujuan: Fokus pada "APA" bukan "BAGAIMANA", kontrak untuk subclass, fleksibilitas implementasi.

🔌 Interface di Dart (implements)

Sejak Dart 3.0, interface class eksplisit. Gunakan implements untuk mengimplementasi kontrak. Bisa multiple implements.

interface class Flyable {
  void terbang() => print('Terbang...');
}

class Bird implements Flyable {
  @override void terbang() => print('Burung terbang tinggi');
}

class Plane implements Flyable {
  @override void terbang() => print('Pesawat terbang cepat');
}

⚙️ Static Members & Method (Utility Class)

Static milik class itu sendiri, diakses via nama class. Berguna untuk konstanta atau fungsi utilitas.

class MathUtils {
  static double pi = 3.14;
  static int add(int x, int y) => x + y;
}

void main() {
  print('Nilai pi : ${MathUtils.pi}');
  print('Hasil add : ${MathUtils.add(10, 20)}');
}

📐 Studi Kasus: Bentuk Geometri (Abstract / implements)

abstract class Bentuk {
  double hitungLuas();
  double hitungKeliling();
  void info() {
    print('Luas: ${hitungLuas()}, Keliling: ${hitungKeliling()}');
  }
}

class Persegi implements Bentuk {
  double sisi;
  Persegi(this.sisi);
  @override double hitungLuas() => sisi * sisi;
  @override double hitungKeliling() => 4 * sisi;
  @override void info() => print('Persegi sisi $sisi → Luas ${hitungLuas()}, Keliling ${hitungKeliling()}');
}

class Lingkaran implements Bentuk {
  double radius;
  Lingkaran(this.radius);
  @override double hitungLuas() => 3.14 * radius * radius;
  @override double hitungKeliling() => 2 * 3.14 * radius;
  @override void info() => print('Lingkaran r=$radius → Luas ${hitungLuas()}, Keliling ${hitungKeliling()}');
}

🧮 Bonus: Implementasi MathUtils (Static methods)

import 'dart:math';

class MathUtils {
  static int factorial(int n) {
    if (n < 0) throw ArgumentError('Tidak untuk negatif');
    return n <= 1 ? 1 : n * factorial(n - 1);
  }
  
  static bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i <= sqrt(n); i++) if (n % i == 0) return false;
    return true;
  }
  
  static double roundToDecimals(double value, int decimals) {
    double mod = pow(10, decimals).toDouble();
    return (value * mod).round() / mod;
  }
  
  static int randomInt(int min, int max) => min + Random().nextInt(max - min + 1);
  static double randomDouble(double min, double max) => min + Random().nextDouble() * (max - min);
  
  static double mean(List<num> numbers) {
    if (numbers.isEmpty) return 0;
    return numbers.reduce((a,b) => a + b) / numbers.length;
  }
  
  static double median(List<num> numbers) {
    if (numbers.isEmpty) return 0;
    List<num> sorted = List.from(numbers)..sort();
    int mid = sorted.length ~/ 2;
    if (sorted.length.isEven) {
      return (sorted[mid - 1] + sorted[mid]) / 2;
    }
    return sorted[mid].toDouble();
  }
}

void main() {
  print(MathUtils.factorial(5));      // 120
  print(MathUtils.isPrime(17));       // true
  print(MathUtils.roundToDecimals(3.14159, 2)); // 3.14
}
⭐ Gunakan utility class ini untuk menyelesaikan tugas nomor 5 secara lengkap.

👩‍💻 Contoh Solusi: Polimorfisme Pekerja

abstract class Pekerja {
  void bekerja();
}

class Programmer implements Pekerja {
  @override void bekerja() => print('💻 Programmer sedang menulis kode Dart...');
}
class Dokter implements Pekerja {
  @override void bekerja() => print('🩺 Dokter memeriksa pasien');
}
class Guru implements Pekerja {
  @override void bekerja() => print('📚 Guru mengajar di kelas');
}

void main() {
  List<Pekerja> tim = [Programmer(), Dokter(), Guru()];
  for (var p in tim) {
    p.bekerja();
  }
}

✅ Dengan polimorfisme, kita bisa memperlakukan semua objek sebagai Pekerja dan memanggil method yang sesuai.

📱 Latihan: Class Tablet (multiple interfaces)

class Komputer {
  void boot() => print('Boot sistem operasi');
}

interface class Kamera {
  void ambilFoto() => print('Mengambil foto');
}

interface class Telepon {
  void telpon(String nomor) => print('Menelpon $nomor');
}

class Tablet extends Komputer implements Kamera, Telepon {
  @override void ambilFoto() => print('Tablet mengambil foto dengan kamera belakang');
  @override void telpon(String nomor) => print('Tablet melakukan panggilan VoIP ke $nomor');
  void tampilkanSpesifikasi() {
    boot();
    ambilFoto();
    telpon('08123456789');
  }
}
📌 Dart tidak mendukung multiple inheritance (extends), namun bisa mengimplementasi banyak interface (implements) dan mewarisi dari satu class (extends).
